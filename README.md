# 📊 Global Superstore Retail Analysis (2011–2024)

A complete end-to-end data analytics project using **Python, Pandas, Matplotlib**, and Jupyter Notebooks.  
This project analyzes **151,290 rows** of retail data across **27 columns**, covering the years **2011 to 2024**.

---

## 📦 Dataset Information

| Metric | Value |
|--------|-------|
| **Total Rows** | 151,290 |
| **Original Data (2011–2014)** | 51,290 rows |
| **Synthetic Added (2015–2024)** | 100,000 rows |
| **Columns** | 27 columns |
| **Year Range** | 2011 → 2024 |

This dataset includes retail orders, profits, customers, categories, segments, regions, shipping cost, discounts, and time-based fields.

---

## 🚀 Project Workflow

### **1️⃣ Data Cleaning**
File: `01_data_cleaning.ipynb`  
- Remove duplicates  
- Fix data types  
- Parse dates  
- Handle missing values  
- Save → `superstore_cleaned.csv`

---

### **2️⃣ Exploratory Data Analysis (EDA)**
File: `02_exploratory_analysis.ipynb`  
- Summary statistics  
- Category & region insights  
- Monthly / yearly patterns  
- Correlation heatmap  
- Outlier detection  
- Save aggregated tables:
  - `yearly_sales.csv`
  - `category_sales.csv`
  - `monthly_sales.csv`
  - `region_sales.csv`

---

### **3️⃣ Matplotlib Visualizations**
File: `03_matplotlib_visuals.ipynb`  
Includes:

- ✔ Yearly Sales Trend  
- ✔ Region-wise Sales Subplots  
- ✔ Category Sales Bar Chart  
- ✔ Sales Distribution Histogram  
- ✔ Discount vs Sales Scatter  
- ✔ Moving Average Sales Trend  
- All visuals saved in `visuals/` folder.

---

### **4️⃣ Automated PDF Report**
File: `04_generate_pdf_report.ipynb`  
Generates **retail_report.pdf** containing all charts in a clean business-friendly layout.

## 📈 Key Insights

1. **Steady growth in sales from 2011 to 2024**  
2. **West region dominates overall revenue**  
3. **Office Supplies is the highest-selling category**  
4. **Sales and profit have a strong positive correlation**  
5. **Discounts do not significantly influence sales**
